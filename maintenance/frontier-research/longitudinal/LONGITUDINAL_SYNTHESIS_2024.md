## Year question
Across 2024, how did the evidence-bearing identity of a scientific visualization expand beyond one rendered image?

## Full-year synthesis
A defensible 2024 communication-evidence model becomes:

```text
scientific/data source
-> claim / research context
-> visual/communication specification
-> renderer + wrapper + backend revision
-> modality
-> user configuration
-> interaction/query state
-> temporal/frame state
-> palette/display state
-> assistive-technology path
-> user/device/task/population context
-> representation-specific validation evidence
-> rendered/interactive artifact
```

This is a non-collapse reasoning model, not a mandatory universal file schema.

## What strengthened across the year
1. representation identity and scientific authority remain separate;
2. renderer/library/wrapper versions can change communication state;
3. invalid/missing-data display policy is not data validity;
4. accessibility evidence attaches to representation and population, not to a figure globally;
5. interactive and temporal state can be material provenance;
6. alternate modalities and assistive renderers do not automatically inherit semantic equivalence;
7. color/accessibility features improve bounded communication dimensions without proving universal conformance;
8. communication transfer != authority transfer.

## Persistent negative space
No Stage establishes universal accessibility, WCAG certification, semantic equivalence across visual/text/audio/touch states, scientific validity from successful render, or independent reproduction of the cited systems.
