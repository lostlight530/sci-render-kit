The earlier A→G narrative already treated the renderer as versioned execution state, not a timeless transformation. Stage H sharpens the **inputs below the nominal library version**: dependency floors, grammar/compiler target and generated spec. In cross-year reasoning, `same code` and `same static pixels` are each weaker than `equivalent scientific, interactive and accessible meaning`.

```text
data + scientific claim
 -> recipe/spec + uncertainty/annotation
 -> wrapper + grammar/compiler + generated spec
 -> installed dependencies / platform + JS runtime
 -> browser/export + interaction/accessibility state
 -> figure artifact + independently assessed claim
```

The figure-production chain is a provenance model, not scientific proof or a universal recipe.
