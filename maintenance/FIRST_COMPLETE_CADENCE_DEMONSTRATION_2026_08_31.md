## 1. Daily demonstration

Command

```bash
python core/maintenance_cadence.py daily --as-of 2026-08-31
```

Daily asks whether demonstrated local communication-stack drift has appeared

```text
Are canonical figure/communication documents and machine contracts present
Did a decorative project profile version reappear
Did forbidden GitHub-governance architecture appear
Is Manifest calibration stale for the daily horizon
Did claim bindings become implicit or inferred
Did uncertainty semantics become stronger than the recipe declares
Did WCAG support become described as certification
Did publisher targets become acceptance claims
Did runtime/backend source presence become runtime-availability proof
```

Daily does not request canonical hashes or history inventory

Expected structural shape

```text
cadence: daily
period_status.calendar_month: calendar-month-close
period_status.stage: closed
baseline_sha256: {}
history_snapshots: []
```

Do not infer

```text
no finding -> scientific validity
communication metadata aligned -> entailment
publisher profile present -> acceptance
accessibility checks present -> WCAG certification
```

## 2. Weekly demonstration

Command

```bash
python core/maintenance_cadence.py weekly --as-of 2026-08-31
```

Weekly reconciles the scientific-communication stack as a system

```text
recipe schema / machine contracts
↔ runtime implementation
↔ Figure Claim Contract
↔ Assertion Basis / Communication Coverage Contract
↔ Communication Transfer Contract
↔ Research Contract
↔ Manifest
↔ README / Architecture
↔ Agent / Contributor / Examples guidance
↔ Frontier Alignment
↔ upstream Auto / Epistemic profile names
```

Weekly questions include

```text
Did a claim binding become inferred from pixels/prose/data
Did a supports relation lose evidence-context visibility
Did uncertainty metadata become statistical validation
Did communication coverage become a quality or truth score
Did a publisher preset become an acceptance validator
Did WCAG scope broaden beyond implemented support
Did communication-transfer lose non-inheritance constraints
Did a historical Day-N note become current capability truth
```

Weekly requests

```text
canonical SHA-256 baseline
historical snapshot inventory
```

When all canonical paths exist, up to **21 canonical hashes** are generated by the scanner
The values must be produced at execution time and are not fabricated here

Historical inventory uses configured `*_DAY_CONSOLIDATION.md` and `STAGE_*.md` patterns

Interpretation

```text
hash != semantic equivalence
weekly consistency != entailment
history inventory != deprecation decision
```
